# Graph Memory Example

Reference corpus / ecosystem specimen for Graph Memory.

This is **not a test suite** and not a collection of synthetic fixtures. It is a reference corpus of real, small coding tasks that evolves over time.

## Purpose

- Provide a bounded, real-world specimen for the Graph Memory ecosystem.
- Start with simple Programs (small real coding tasks) and grow naturally toward multi-module programs, graph-oriented programs, and eventually real applications.
- Serve as a container for independent Projects once the corpus matures.

## Corpus evolution

1. **Simple Programs** — small real coding tasks (e.g., Fibonacci).
2. **Multi-module programs** — programs composed of interacting modules/files.
3. **Graph-oriented programs** — programs with explicit graph structure.
4. **Real applications** — larger, practical applications.

Blocks are not formalized at this stage. They will emerge naturally as programs begin to consist of multiple interrelated modules/files.
