## Representation

Flat **`board: [Int]`** of length `n`; **`board[row]`** is the queen column for that row, or **`-1`** when unassigned. No matrix, map, or auxiliary set types.

---

## Constraints (`queens_safe_at`)

For a candidate `(row, col)`, reject same column as any prior row and reject diagonal conflicts against rows `0..row-1` (unique column and non-conflicting diagonals among assigned rows).

---

## Mutation and backtracking

Shared board mutated in place with **`board.set(row, col)`** before recursion; after exploring each column, **`board.set(row, -1)`** restores the row. Board is passed by reference through recursive calls (no per-call board copy).

`count_n_queens_solutions(n: Int) -> Int?` — **`n < 0` → `null`**; **`n = 0` → `1`** (empty-board convention); **`n > 0` →** count of valid complete placements.
