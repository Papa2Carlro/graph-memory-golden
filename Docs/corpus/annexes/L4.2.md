## Pipeline (landed specimen)

encode (`rle_encode`) → validate (`validate_encoded_rle`) → decode (`decode_rle`) → verify (`rle_roundtrip_verified` / `text_equals_chars`).

---

## Representation

Encoded runs as parallel **`[Char]`** (run symbols) and **`[Int]`** (run lengths). **`decode_rle`** appends decoded scalars into an output **`[Char]`** buffer; it does **not** return or construct a **`String`**.

---

## Encoded invariants (`validate_encoded_rle`)

`chars.count()` equals `lens.count()`; every run length is **positive**; adjacent runs use **distinct** `Char` values; sum of run lengths equals the decoded scalar count implied by a valid roundtrip (and matches the original `String` scalar count on success).

---

## Rejection

Invalid encodings (count mismatch, zero/negative length, adjacent duplicate runs) are rejected **before** decode proceeds (`validate_encoded_rle`; `decode_rle` returns false when validation fails).

---

## Validation record (honest)

`rle_roundtrip_verify() -> Bool` aggregates wired checks (§11); `rle_roundtrip_sample` demonstrates encode/decode only — golden roundtrips: empty, singleton (`"a"`), repeated (`"aaaa"`), alternating (`"abc"`), mixed runs (`"aabbbcc"`, `"aaabbbaa"`); negative validation: count mismatch, zero length, negative length, adjacent duplicate; decode guard on invalid input; Unicode scalar roundtrip **`"aπb"`**. Verification is **source-level** (specimen + sample wiring); **not** end-to-end compiler/runtime execution.

---

## Language gap (corpus honesty, not an owner decision)

Canonical construction of `String` from `[Char]` remains **OPEN**. L4.2 verifies Unicode scalar equivalence without claiming that `decode_rle` returns `String`. See [GAPS.md §4](../GAPS.md#4-classic-l4-language-runtime-and-corpus-gaps-841843).
