## Representation

Directed graph as **`adjacency: [Int]`** with **`adjacency.count() == n * n`**; cell **`adjacency[u * n + v]`** is **`1`** (edge **u → v**) or **`0`** (no edge). **`queue: [Int]`** with **head-index** dequeue (no front removal). **`visited: [Bool]`**, **`distance: [Int]`** (unvisited **`-1`**), **`predecessor: [Int]`** (missing **`-1`**).

---

## Traversal

FIFO by advancing queue head; neighbors inspected in **ascending** vertex order; first discovery sets **`distance[v] = distance[u] + 1`** and **`predecessor[v] = u`** (deterministic tie-breaking for equal-length paths).

---

## Reconstruction

Walk predecessor links from target toward source, reverse into **`[Int]`** from source to target; no sentinel **`-1`** in the returned path.

---

## Path invariants (reference intent)

Each vertex discovered at most once; reconstructed path starts at source and ends at target; consecutive vertices correspond to directed edges with cell **`1`**; edge count equals BFS distance when reachable.

---

## Input/output contract (program-specific, owner decision A1=C — DECIDED — not a global GS rule)

- **`bfs_input_valid(adjacency, n, source, target) -> Bool`** — shape (`n >= 0`, `n × n` matrix), vertex indices in range, and **binary** matrix cells (**`0`** or **`1`** only).
- **`bfs_shortest_path_flat(n, adjacency, source, target) -> [Int]?`** — calls the same validation; on failure returns **`null`**.
- **Invalid input:** **`bfs_input_valid` → false**; BFS → **`null`** (caller must check validation first to distinguish from unreachable).
- **Valid but unreachable target:** **`bfs_input_valid` → true**; BFS → **`null`**.
- **Valid and reachable:** **`bfs_input_valid` → true**; BFS → path **`[Int]`** from source to target.
- **`source == target`:** singleton path **`[source]`** when input is valid.

**Two-call distinction (A1=C):** callers that need to separate **invalid input** from **unreachable** must consult **`bfs_input_valid`** before interpreting a **`null`** path from **`bfs_shortest_path_flat`**.
