## Grammar (initial target, program-specific)

Binary `+` `-` `*` `/`; parentheses; non-negative **ASCII_DIGIT+** integer literals; ASCII **space** whitespace; **no unary** `+`/`-`. Rejects empty input, malformed operators/parentheses, implicit multiplication, invalid characters.

---

## Token representation

Parallel **`kinds: [Int]`** and **`values: [Int]`** (INTEGER, OPERATOR, LEFT_PAREN, RIGHT_PAREN); postfix stream uses the same parallel shape without parentheses.

---

## Shunting-yard

Operator stack with parenthesis marker; precedence `*/` > `+-`; **left-associative** pop rule (`>=`); deterministic infix order preserved in postfix output.

---

## Arithmetic (program-local guards — not global GS overflow law)

`add_int64`, `sub_int64`, `mul_int64`, `div_int64` gate **`null`** on overflow, divide-by-zero, and **`INT_MIN / -1`**. **`mul_int64`** overflow checks use **`mul_pos_would_overflow`** with **`Int / Int` only when both operands are strictly positive** (unambiguous trunc-toward-zero for the specimen); magnitudes for negative factors come from **`sub_int64(0, ·)`** and explicit **`INT_MIN`** / **`-1`** special cases — **no** mixed-sign division in guards. **`div_int64`** still applies surface **`/`** only after guards; goldens use **exact** positive divisions only. Integer literals reuse L4.1-style **Int{64}** magnitude overflow checks during lex (`magnitude_would_overflow` / `parse_uint_lexeme`).

---

## Result contract

**`evaluate_expression(text: String) -> Int?`** — invalid lex/grammar/shunting/eval → **`null`**; success → **`Int`**.

## Validation record (honest)

`shunting_yard_eval_verify() -> Bool` aggregates wired checks (§11); `shunting_yard_eval_sample` demonstrates evaluation only — precedence, left associativity, nested parentheses, whitespace, multi-digit literals, negative **results** via subtraction (`3-5`), division by zero, malformed/unary/implicit-mul cases; **Int{64}** max literal, lex overflow literal, add/mul overflow rejection; **multiply sign-quadrant** goldens (`12*34`, `(0-25)*4`, `4*(0-25)`, `(0-6)*(0-7)`); **zero** multiplication; **`INT_MAX*1`**, **`INT_MIN*1`** via subtraction-built **`INT_MIN`**; reject **`INT_MIN*2`**, **`INT_MIN*(0-1)`**, **`INT_MAX*INT_MAX`**.
